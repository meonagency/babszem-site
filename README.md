# babszem-site

Babszem Virágműhely weboldal (Next.js, App Router). Fejlesztő: MeOn Agency.

- `npm install` és `npm run dev`
- Betűtípusok: Cinzel (címsor, logó) és Jost (szöveg), saját kiszolgálással (Fontsource)
- Logó ikon: `app/mark.js`, favicon és apple-icon kódból generálva
- Jelenleg teszt oldal, `noindex` beállítással
